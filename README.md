# Logix Studio

Design FPGAs by drawing schematics.

**Coming Q1 2027.** This repository is a placeholder; the work hasn't started here yet. See the [Logix Studio page](https://www.openlogix.org/studio/) for what's planned.

Logix Studio is part of [Open Logix](https://www.openlogix.org/): free, open source tools for FPGA design that install in one step, run on macOS, Windows and Linux, and need no separate toolchain.
